# Chan-Tat Ng

Personal academic website for Chan-Tat Ng. The site uses static HTML and CSS and publishes from the root of the `main` branch on GitHub Pages.

Open `index.html` to preview locally. The typefaces load from Google Fonts, with local serif and sans-serif fallbacks.

## Updating the site

- Edit the relevant HTML page and update the month in its footer. Use `YYYY-MM` for both the displayed value and the `datetime` attribute.
- Add the full citation to `publications.html` or `presentations.html`. Update the selected entries on `index.html` when appropriate.
- Maintain the CV in Google Drive. Replacing its contents while retaining the same file ID keeps the navigation link current.
- Edit `css/style.css` for visual changes and `assets/favicon.svg` for the tab icon.
